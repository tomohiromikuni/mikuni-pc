## 1. 定期実行の設定（Supabase）　※未実施

**これをやるまで動かないもの**
- スマホへの通知の送信（お知らせ・チャット・出欠の通知、再通知）
- 予約したお知らせの自動配信（「今すぐ配信」は動きます）
- 回答期限を過ぎた出欠・アンケートの自動締切（期限後の回答は締切前でも受け付けません）
- 修了予定日の90日後の自動停止
- 祝日データの毎月の自動更新（「通知と設定」画面のボタンで手動取り込みはできます）

**手順**
1. Supabase（mics-pc-tokyo）→ Database → Extensions で `pg_cron` と `pg_net` をオンにする
2. [`supabase/setup/cron.sql`](../supabase/setup/cron.sql) の中身をコピーして、SQL Editor の新しいタブに貼り付ける
3. ★の部分を書き換える（4か所）
   - `'★https://mics-pc.vercel.app/api/cron/dispatch'` → ★を消す
   - `'★https://mics-pc.vercel.app/api/cron/holidays'` → ★を消す
   - `'Bearer ★CRON_SECRETの値'`（2か所）→ `'Bearer '` のあとに、Vercel に登録した CRON_SECRET の値を貼る（例：`'Bearer P_V2G0xxxx'`）
4. Run を押す
5. 管理画面の「設定チェック」で ⚠️ が消えたか確認する
